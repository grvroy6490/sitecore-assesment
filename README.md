# Sitecore headless: hands-on starter

A small Next.js (App Router) app for the live coding round.

1. `nvm use` (Node 22), then `npm install`
2. `npm run dev`
3. Open `TASKS.md` and follow it.

Rules: no AI tools (Copilot, ChatGPT, etc.). Official docs are fine.
The editor settings in `.vscode/` turn Copilot off. Please leave them as they are.
